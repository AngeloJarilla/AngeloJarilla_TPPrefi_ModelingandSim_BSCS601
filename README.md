# Student Score Distribution Visualization

## Overview

This project reads an Excel file containing student scores and generates histograms to visualize different types of score distributions.

## What it does

* Loads an Excel file with student score data
* Creates histograms with density curves for each subject/column
* Displays different distribution types such as:

  * Normal distribution
  * Bi-modal distribution
  * Unitary distribution
  * Left-skewed (negative skew)
  * Right-skewed (positive skew)
* Saves the output as an image file

## Output

* A figure showing multiple histograms in one layout
* Saved as: `student_score_histograms.png`

## Libraries used

* pandas
* seaborn
* matplotlib

## How to run

1. Make sure the Excel file path is correct
2. Install required libraries:

   ```
   pip install pandas seaborn matplotlib openpyxl
   ```
3. Run the script

## Result

The code helps visualize how student scores are distributed across different patterns using histograms with smooth density curves.
